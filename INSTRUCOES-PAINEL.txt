ROMMO — PACOTE LIMPO COM PAINEL RESPONSIVO

O projeto mantém a loja e a API existentes. O painel recebeu uma atualização visual leve, organizada e responsiva para desktop, tablet e celular.

PARA USAR NO SEU COMPUTADOR:
1. Extraia o ZIP numa pasta nova ou faça backup do projeto atual antes de substituir arquivos.
2. Se quiser aplicar apenas a atualização do painel, copie os arquivos em rommo-site/gestao-6f2a/ para a mesma pasta do seu projeto.
3. Na pasta do projeto, rode npm install e depois npm run dev.
4. Abra http://127.0.0.1:8787/gestao-6f2a/ e pressione Ctrl+F5.

SEGURANÇA:
- O ZIP omite .dev.vars, .wrangler e node_modules. Configure seu próprio .dev.vars localmente; não envie senhas pelo chat.
- Não execute migrações remotas nem deploy até testar localmente e revisar configuração/segredos.
- Esta entrega atualiza o visual do painel existente; não adiciona módulos que a API ainda não oferece.
